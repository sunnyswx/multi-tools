# Multi Tools - 多功能在线工具网站

一个集合了10个常用在线工具的现代化网站。

## 工具列表

1. **Image Compressor** - 图片压缩工具
2. **PDF Converter** - PDF转换工具
3. **QR Generator** - 二维码生成器
4. **Password Generator** - 密码生成器
5. **Color Picker** - 颜色选择器
6. **Word Counter** - 字数统计器
7. **Timezone Converter** - 时区转换器
8. **Countdown Timer** - 倒计时器
9. **Unit Converter** - 单位转换器
10. **Online Calculator** - 在线计算器

## 特性

- ✅ 响应式设计
- ✅ 多语言支持（中文、英文、日文、韩文、西班牙文、法文）
- ✅ 本地处理，保护隐私
- ✅ 无广告干扰（预留广告位）
- ✅ 快速加载

## 技术栈

- HTML5 + CSS3 + JavaScript
- Cloudflare Pages 部署
- GitHub Actions CI/CD
